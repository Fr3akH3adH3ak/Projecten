## System Access Simulator

Een hackerspel in de browser, gemaakt met HTML, CSS, JavaScript en Bootstrap 5.
Drie levels, geluid, highscores, een wachtwoordtest en Matrix-regen op de
achtergrond (typ `matrix`). Alle servers en wachtwoorden in het spel zijn verzonnen.

Openen: download `system-access-simulator/index.html` en dubbelklik erop.

## Matrix-regen in C

Vallende tekens over je hele terminal, met kleur- en snelheidskeuze.

```
gcc -Wall -Wextra matrix_v2.c -o matrix_v2
./matrix_v2 groen 50
```

Stoppen met Ctrl+C.
